# Tour Africa

A modern React web application for exploring and booking African travel experiences.

## Features

- **Home Page** - Hero section, featured destinations, categories, testimonials, gallery, FAQ
- **Destinations** - Search, filter by category/price/location
- **Explore** - Curated travel experiences
- **Authentication** - Login and Signup with social auth
- **Onboarding** - Personalized travel preferences
- **Payment** - Secure booking and payment flow
- **Reviews** - Leave and read traveler reviews
- **Dashboard** - Manage trips and profile
- **Travel Requirements** - Visa, health, and document info
- **Destination Details** - Full trip information with booking

## Tech Stack

- React 18 + Vite
- React Router DOM
- Lucide React (icons)
- CSS3 with CSS Variables

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
